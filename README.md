# JavaScript Callback Practice

This repository contains three exercises to practice asynchronous JavaScript using callbacks and `setTimeout()`.

### Problems

1. **Fetch & Process User Data** — Fetch user details, process a welcome message, and simulate saving it.
2. **Read & Transform File Data** — Read text, convert it to uppercase, and reverse the string.
3. **Online Order Simulation** — Simulate order placement, payment processing, and delivery.

### Concepts Covered

- Callbacks and callback chaining
- Asynchronous operations
- Error handling
- `setTimeout()`
- Sequential execution
